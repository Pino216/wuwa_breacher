# 鸣潮入侵协议解题器 (WuWa Breacher)

基于 Tesseract.js OCR 的鸣潮 × 赛博朋克2077 入侵协议小游戏自动解题器。**纯浏览器端运行，无需安装任何东西。**

> 🔗 **在线使用**: https://Pino216.github.io/wuwa_breacher/

## 快速开始

```
1. 截取游戏中的入侵协议面板
2. 打开网页，拖拽截图上传（或 Ctrl+V 粘贴）
3. 框选矩阵区 🟢 和目标序列区 🔵
4. 点击 SOLVE → 自动识别并标注路径
```

| 按钮 | 说明 |
|------|------|
| ▶ **SOLVE** | 按框选区域识别并求解 |
| 🔍 **调试图** | 展开查看实际送入 OCR 的裁剪图片 |

## 输出示例

```
Buffer=6 (6步)  全部匹配: 目标1, 目标2
路径值: BD → 1C → FF → 7A → BD → 55

   1C    [BD 1] 7A     FF
  [BD 5] 7A     1C    [7A 4]
  [55 6] 1C     7A     1C
   7A    [1C 2] 55    [FF 3]
```

网格中用 `[值 步数]` 标记点击位置，数字为点击顺序。结果区会同时在截图上叠加绿色路径标注。

## 游戏规则

| 规则 | 说明 |
|------|------|
| **矩阵** | 4×4 到 7×7 的 hex 值网格 |
| **目标序列** | 2~6 条，每条 2 到 5 个 hex 值 |
| **移动** | 交替行/列，不能重复走格子 |
| **字节值** | `1C` `55` `7A` `BD` `E9` `FF`（共 6 种） |

## 技术栈

- **Tesseract.js** — 浏览器端 OCR（WASM），通过 BootCDN（又拍云）加载
- **Canvas API** — 图像预处理
- 纯前端，零服务器，可部署在 GitHub Pages

> 首次使用会下载约 5MB OCR 语言包，之后缓存。国内用户如遇加载慢，页面会自动切换到备用 CDN。
