# 鸣潮入侵协议解题器 (WuWa Breacher)

基于 Tesseract.js OCR + 像素模板匹配的鸣潮 × 赛博朋克2077 入侵协议小游戏自动解题器。**纯浏览器端运行，无需安装任何东西。**

> 🔗 **在线使用**: https://Pino216.github.io/wuwa_breacher/

## 快速开始

```
1. 截取游戏中的入侵协议面板（QQ截图 Ctrl+C 即可）
2. 打开网页，Ctrl+V 粘贴（或拖拽/点击上传）
3. 框选矩阵区 🟢 和目标序列区 🔵
4. 点击 SOLVE → 自动识别并求解
```

| 功能 | 说明 |
|------|------|
| **SOLVE** | 自动识别矩阵和目标序列，求解最优路径 |
| **编辑格子** | 识别错误可直接点击格子修改值 |
| **重新求解** | 修改后点击重新计算路径 |
| **模板模式** | 勾选后矩阵区走像素匹配，不依赖 OCR（默认开启） |
| **保存模板** | 修正后保存为模板，下次自动匹配 |
| **调试图** | 展开查看 OCR 原始输出和预处理图像 |

## 支持的值类型

| 类型 | 数量 | 值 |
|------|:----:|----|
| Hex 值 | 6 | `1C` `55` `7A` `BD` `E9` `FF` |
| 双字符字母码 | 11 | `GO` `MO` `OD` `IN` `RN` `GS` `OL` `IS` `AR` `MY` `MA` |
| 单字符字母码 | 3 | `M` `N` `O` |

## 技术栈

- **Tesseract.js** — OCR 引擎（WASM），通过 BootCDN（又拍云）加载，含 CDN 备用回退
- **Canvas API** — 图像预处理（灰度→二值化→反色）
- **像素模板匹配** — 矩阵区可切换为像素比对，内置 15 个字符模板
- **DFS 求解器** — 带剪枝的深度优先搜索，支持 Buffer 2~9
- 纯前端，零服务器，单 HTML 文件

> 首次使用会下载约 5MB OCR 语言包，之后缓存。
