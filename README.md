# 鸣潮破解协议解题器 (WuWa Breacher)

基于 Tesseract.js OCR 的鸣潮联动赛博朋克2077 破解协议小游戏自动解题器。

## 快速开始

```bash
# 1. 安装依赖
npm install

# 2. 启动网页服务
.\serve.cmd
# 浏览器打开 http://localhost:3000

# 3. 截取游戏中的破解协议面板，拖拽上传
# 4. 用鼠标框选矩阵区（绿色）和目标序列区（蓝色）
# 5. 点击 SOLVE → 自动识别 + 求解 + 标记步骤
```

## 使用方式

### 网页端（推荐）

```
.\serve.cmd
# → http://localhost:3000
```

流程: **上传截图 → 框选区域 → SOLVE → 查看结果**

- 🟢 绿色框 = 矩阵区域（拖动/缩放）
- 🔵 蓝色框 = 目标序列区域
- ⚡ AUTO = 使用默认裁剪坐标
- ▶ SOLVE = 使用自定义框选坐标
- 🔍 调试图 = 查看实际送入 OCR 的裁剪图片

### 命令行

```bash
node breacher.js 截图.png
node breacher.js 截图.png --debug   # 显示 OCR 原始输出
```

## 游戏规则

| 规则 | 说明 |
|------|------|
| **矩阵** | 4×4 ~ 7×7 的 hex 值网格 |
| **目标序列** | 2~6 条，每条 2~5 个 hex 值 |
| **Buffer** | 2~9 步 |
| **移动** | 交替行/列，不能重复走格子 |
| **起点** | 可以从第一行任意列出发 |
| **匹配** | 路径的连续子串包含目标序列即得分 |
| **字节值** | `1C` `55` `7A` `BD` `E9` `FF`（共 6 种） |

## 技术方案

```
截图 → 缩放到 1562px → 按框选坐标裁剪
  → 自动放大(≥480px) → 灰阶二值化(阈80) → 反色(白底黑字)
  → Tesseract.js OCR (PSM.SINGLE_BLOCK)
  → Levenshtein 模糊匹配清洗 token → 矩阵行对齐 → 求解器
```

### 图像预处理

- **固定阈值二值化** (brightness > 80 → 文字→黑, 背景→白)
- **反色**：白底黑字（Tesseract 最优识别格式）
- **自动放大**：裁剪区 < 480px 时整数倍放大
- **矩阵区** +5px 扩展防切边
- **目标区** -3px 收缩防边缘干扰

### OCR 清洗策略

采用**分层匹配**替代笨重的硬编码映射表：

1. `BYTE_MAP` 直接命中
2. `CHAR_MAP` 单字符直接匹配
3. `KNOWN_FIX` 已知特殊误读（AD→1, IC→1, 3D→B...）
4. `CHAR_FIX` 常见单字符替换（I→1, S→5, G→5...）
5. 双字符拆分识别
6. **Levenshtein 编辑距离**（阈值 1）模糊匹配
7. 矩阵交叉验证（目标值不在矩阵中时自动修正）

## 项目文件

| 文件 | 说明 |
|------|------|
| `breacher.js` | 主管线：图像处理 + OCR + 求解 + HTTP 服务 |
| `index.html` | 网页前端：拖拽上传 + 框选裁剪 + 网格可视化 |
| `ocr-pipeline.js` | OCR 独立模块（可单独引用） |

| `.gitignore` | Git 忽略规则 |

## 依赖

- **tesseract.js** — 浏览器端 OCR 引擎
- **jimp** — 图像处理（缩放/裁剪/二值化）

## 注意

- Node.js ≥ 18，需设置 `NODE_OPTIONS=--openssl-legacy-provider`
- 首次运行 Tesseract 会自动从 CDN 下载语言包
- 全屏截图建议使用网页端框选功能
- 框选越精确，识别效果越好
